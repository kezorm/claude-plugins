# Changelog — journal skill

Template versions and what changed between them.

## v1.0.0 (current)

**Entry template**
- Sections: Done, Why, Tried and rejected, Verified, Open, Next
- All sections optional except date and title

**ADR template**
- Sections: Context, Decision, Alternatives rejected, Consequences
- Status, Date, and Alternatives rejected are required fields
- Consequences split into: Accepted costs, Benefits, Constrains, Revisit if

**When to update your entries:**

If your JOURNAL.md entries carry version comments (`<!-- journal entry template v0.x.x -->`), you can compare them to the current version above. Entry format is stable; updates are infrequent and backward-compatible. If your entries don't have a version comment yet, they're using the current format.

**When to update your ADRs:**

ADRs carry version comments in their template. If you have older ADRs without a version comment, they're using v1.0.0 format—no update needed. If a template change requires restructuring, a migration note will appear here.
